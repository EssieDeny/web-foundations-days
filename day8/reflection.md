# Day 8 Reflection

The most difficult concept in this course was understanding how different system components work together when traffic increases. Initially, caching, load balancing, database transactions, and queues seemed like separate solutions. Through the daily assignments, I learned that each component solves a different problem. Caching reduces repeated reads, load balancing distributes requests, and database transactions protect data when multiple users perform operations simultaneously. Breaking complex problems into smaller steps and applying the concepts to practical examples helped me understand them better.

Based on the feedback and lessons from my capstone, I would improve the explanation of how the system handles high traffic and maintains data consistency. I would make my assumptions clearer, distinguish average traffic from peak traffic, and explain how database constraints and transactions prevent conflicting updates. I would also improve the architecture diagram to make the relationships between the client, API, cache, database, and background workers easier to understand.

Next, I want to learn more about cloud computing and deployment, particularly Microsoft Azure. I plan to study how to deploy applications, configure monitoring, manage databases, and scale services according to demand. I also want to practise building REST APIs and implementing database transactions in a small working project. This will help me progress from designing systems on paper to understanding how their components work together in a real application.
